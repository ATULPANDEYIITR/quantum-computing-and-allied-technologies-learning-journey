# Quantum Teleportation | Quantum Information Transfer

## Scope

This repository artifact models **quantum teleportation**, a protocol for transferring an unknown quantum state from one physical qubit to another using a pre-shared entangled pair and a classical communication channel.

The protocol is often described as information transfer, but that description requires an important qualification. The unknown quantum state is not transmitted as a classical description of its amplitudes. Alice does not measure the state to discover its complete quantum description. Instead, the protocol combines entanglement, a joint measurement, two classical bits, and conditional quantum operations so that Bob's qubit becomes equivalent to Alice's original state.

The three implementations use different perspectives:

- The Python program emphasizes explicit quantum-state mathematics, density matrices, partial traces, measurements, fidelity, and stochastic channel noise.
- The JavaScript program emphasizes an event-driven representation of the protocol, where quantum operations and classical communication appear as observable protocol phases.
- The C++ program treats teleportation as a compact systems case study with typed state representations, explicit validation, deterministic branch verification, and a noisy-channel experiment.

The central relationship is:

**unknown quantum state → entangled resource → Bell-basis measurement → two classical bits → conditional correction → reconstructed quantum state**

The protocol does not transmit matter, does not duplicate the original state, and does not permit usable faster-than-light communication.

---

## Quantum state being transferred

A general pure qubit can be written as

`|ψ⟩ = α|0⟩ + β|1⟩`

where `α` and `β` are complex amplitudes satisfying

`|α|² + |β|² = 1`.

The complex phase relationship between `α` and `β` is part of the quantum information. A teleportation implementation that only tests `|0⟩`, `|1⟩`, and real-valued superpositions can miss important behavior. The implementations therefore include complex-amplitude states such as states containing an imaginary component.

A global phase does not change the physical pure state. Consequently, fidelity is a more useful correctness criterion than direct equality of amplitude arrays.

For two pure states, the fidelity used by the implementations is

`F = |⟨ψ|φ⟩|²`.

For identical physical states, `F = 1`.

## The three-qubit teleportation register

The protocol requires three logical qubits:

| Qubit | Role |
|---|---|
| `q0` | Alice's unknown input state |
| `q1` | Alice's half of the pre-shared Bell pair |
| `q2` | Bob's half of the pre-shared Bell pair |

The initial three-qubit state is

`|ψ⟩ ⊗ |Φ⁺⟩`

where the Bell state is

`|Φ⁺⟩ = (|00⟩ + |11⟩) / √2`.

The ordering matters because the simulators use computational-basis indices such as `|000⟩`, `|001⟩`, through `|111⟩`. A gate acting on `q0` is not interchangeable with the same gate acting on `q2`.

---

## Entanglement resource

Alice and Bob first share an entangled Bell pair.

The Bell state is generated by starting with `|00⟩`, applying a Hadamard gate to the first qubit, and then applying CNOT from the first qubit to the second:

`|00⟩ → H(q1) → CNOT(q1,q2)`

The resulting state is

`(|00⟩ + |11⟩) / √2`.

The two qubits cannot be described as two independent pure states. Their joint amplitudes contain correlations that are not captured by assigning one ordinary two-component state vector to each qubit.

The Python implementation makes this distinction explicit through a density-matrix calculation. It forms `|Φ⁺⟩⟨Φ⁺|` and performs a partial trace to obtain one qubit's reduced density matrix. The result is the maximally mixed single-qubit density matrix

`[[1/2, 0], [0, 1/2]]`.

This is an important reason density matrices are useful in quantum information. A subsystem of an entangled pure state can itself be mixed.

---

## Bell-basis measurement

Alice does not independently measure `q0` and `q1` in their original computational basis.

Instead, she transforms the Bell basis into the computational basis using:

`CNOT(q0,q1)`

followed by

`H(q0)`.

After that transformation, measuring `q0` and `q1` produces two classical bits.

The four possible outcomes are:

| Alice's bits | Bob's required correction |
|---|---|
| `00` | `I` |
| `01` | `X` |
| `10` | `Z` |
| `11` | `XZ` |

The ordering of the bits is important. The implementations consistently treat the first measurement bit as controlling the `Z` correction and the second as controlling the `X` correction.

Alice's measurement also collapses the global state. Bob's qubit therefore occupies a branch-dependent state related to the original input by a Pauli operation.

---

## Classical communication

The measurement produces ordinary classical information.

Alice sends two classical bits to Bob. These bits do not contain a classical description of `α` and `β`. They identify which correction Bob must apply to his entangled qubit.

This distinction is fundamental:

- Entanglement supplies the quantum correlation.
- Alice's measurement creates the classical branch information.
- Classical communication tells Bob which correction is required.
- Bob's conditional operation reconstructs the original state.

Bob cannot finish the protocol using entanglement alone.

Because the classical message must travel through an ordinary communication channel, teleportation cannot be used as a faster-than-light classical communication mechanism.

---

## Conditional correction

Bob's correction is a Pauli operation selected by Alice's two classical bits.

For the convention used by these implementations:

- `00` requires no correction.
- `01` requires `X`.
- `10` requires `Z`.
- `11` requires `X` and `Z`.

The order of `X` and `Z` can introduce a global phase because the Pauli operators anticommute:

`XZ = -ZX`.

That sign does not alter the physical pure state, which is why fidelity is the appropriate correctness measurement.

After the correction, Bob's state has fidelity one with the original state in the ideal simulation.

---

## Why teleportation is not cloning

Quantum teleportation does not create two simultaneous copies of an unknown quantum state.

Alice's original qubit participates in the Bell-basis measurement. The measurement changes the original quantum information and prevents Alice from retaining an untouched copy of the state.

Bob subsequently obtains the state on a different physical qubit.

The protocol therefore transfers the quantum state rather than creating an independent duplicate. This is consistent with the no-cloning theorem.

The Python program explicitly documents this constraint, while the JavaScript and C++ implementations represent the protocol as a state transition in which Alice's measurement precedes Bob's reconstruction.

## Python implementation

The Python program provides the most mathematically detailed simulator.

### State-vector representation

A quantum register with `n` qubits is represented by `2^n` complex amplitudes.

The implementation uses Python lists of complex numbers rather than an external numerical package. This makes the quantum operations visible directly in the source.

The functions `qubit_state`, `basis_state`, `tensor_product_vectors`, and `normalize` establish the state representation.

The explicit tensor product is important because teleportation operates on a joint three-qubit state rather than on three unrelated objects.

### Gate application

The program defines the common single-qubit operators:

- Identity
- Pauli-X
- Pauli-Y
- Pauli-Z
- Hadamard
- General phase rotation

`apply_single_qubit_gate` applies a two-by-two matrix to one qubit inside a multi-qubit state without explicitly constructing the complete system matrix.

`apply_controlled_x` and `apply_controlled_z` implement controlled operations by examining computational-basis bits.

This is particularly useful for learning how a local gate becomes an operation on the complete tensor-product state.

### Measurement and collapse

`measure_two_qubits` calculates the probability of each possible two-bit outcome, samples one outcome, and then projects the state onto the corresponding subspace.

The resulting state is normalized again after projection.

This makes the distinction between a quantum probability distribution and a deterministic classical branch explicit.

### Density matrices

The Python implementation includes `outer_product`, `partial_trace_keep_one_qubit`, and `matrix_trace`.

These functions demonstrate why state vectors are insufficient for describing every subsystem in an entangled system.

The Bell pair is a pure joint state, but the reduced state of either individual qubit is mixed.

### Fidelity

`single_qubit_fidelity` calculates the squared magnitude of the inner product between the expected and reconstructed states.

This lets the simulator verify teleportation for states containing:

- computational-basis amplitudes,
- equal superpositions,
- negative amplitudes,
- complex relative phases,
- non-trivial complex amplitude combinations.

### Noise

The Python implementation also includes a simple stochastic Pauli channel.

With a configurable probability, one of `X`, `Y`, or `Z` is introduced into Bob's state.

This is not a full physical noise model, but it demonstrates an important engineering distinction: the teleportation circuit can be mathematically correct while the physical channel still reduces the fidelity of the transferred state.

## JavaScript implementation

The JavaScript implementation approaches the same protocol as an event-driven system.

### Complex arithmetic

JavaScript does not have a built-in complex-number primitive suitable for this simulation, so the file defines a `Complex` class.

The class provides:

- addition,
- subtraction,
- multiplication,
- conjugation,
- magnitude,
- normalization support,
- formatted output.

This keeps the quantum-state operations explicit without introducing an npm dependency.

### Event-driven protocol

`TeleportationProtocol` extends `EventTarget`.

The protocol emits events for meaningful lifecycle transitions such as:

- entanglement preparation,
- Alice's measurement,
- classical-message creation,
- Bob's pre-correction state,
- protocol completion.

This is a useful systems perspective because quantum teleportation has both quantum and classical stages.

The quantum circuit does not exist as an isolated mathematical object. A practical implementation must coordinate quantum operations with classical control information.

### Deterministic demonstrations

The JavaScript file includes a seeded pseudo-random generator so examples can be reproduced.

This matters when debugging a protocol simulator. If every execution produces an unrelated random branch, a developer can have difficulty distinguishing a protocol defect from normal measurement randomness.

A deterministic test seed makes a failing branch repeatable.

### Noise experiment

The JavaScript implementation separates the ideal teleportation path from a stochastic Pauli channel.

The noisy trial:

`prepare → Bell measurement → extract Bob state → inject noise → classical correction → fidelity`

shows that channel reliability is distinct from protocol correctness.

## C++ case study

The C++ program treats teleportation as a small quantum information transfer engine.

Its central object is `TeleportationEngine`.

The engine accepts a validated one-qubit source state and executes the complete transfer:

`source validation → Bell-pair preparation → Bell-basis transformation → measurement → classical outcome → Bob correction → fidelity`

### Typed state representation

`QuantumState` owns a vector of complex amplitudes.

The class validates that the dimension is a power of two and normalizes the state.

This prevents common state-model errors such as:

- empty vectors,
- non-quantum dimensions,
- zero-norm states,
- accidentally unnormalized amplitudes.

### Gate operations

`applySingleQubitGate` applies a two-by-two gate to a specified qubit in the register.

`applyCNOT` explicitly models the control-target relationship.

The implementation avoids constructing a complete eight-by-eight matrix for the three-qubit circuit. It transforms basis indices directly, which keeps the case study compact and makes the qubit addressing mechanism easier to inspect.

### Protocol transaction

`TeleportationTransaction` captures:

- the original input,
- Alice's two classical measurement bits,
- Bob's state before correction,
- Bob's state after correction,
- final fidelity.

This representation makes the information flow explicit.

The measurement bits are not hidden inside the quantum state. They are a separate classical artifact generated by the measurement stage and consumed by the correction stage.

### Audit layer

`QuantumTransferAudit` verifies:

- normalization,
- valid classical measurement bits,
- ideal teleportation fidelity.

This models an important systems principle: a protocol implementation should not merely produce output; it should enforce invariants that identify invalid states and unexpected behavior.

### All four correction branches

The C++ program explicitly checks all four classical outcomes.

This matters because random testing alone cannot guarantee that every correction branch has been exercised in a small number of trials.

The branch verification checks the correction mapping for:

`00`, `01`, `10`, and `11`.

Each branch must return a state with fidelity one against the source state in the ideal mathematical model.

## Information-flow architecture

The implementations can be viewed as a small hybrid quantum-classical pipeline:


Alice                                                Bob

  |                                                   |
  | unknown |ψ⟩                                      |
  |                                                   |
  +---------- prepare shared Bell pair --------------+
              |                       |
             q1                      q2
              \_______________________/
                       entanglement

  | Bell-basis measurement                            |
  |                                                   |
  |------ classical bits b0,b1 --------------------->|
  |                                                   |
  |                                                   | conditional X/Z
  |                                                   |
  |                                                   | reconstructed |ψ⟩

The important boundary is between the quantum and classical information paths.

The Bell pair is quantum information infrastructure. Alice's measurement result becomes classical information. Bob uses that classical information to select a quantum operation.

## Measurement outcomes and state transformation

Before correction, Bob's state depends on Alice's measurement.

Conceptually, the four branches have the form:

| Measurement | Bob's pre-correction state | Bob's operation |
| ----------- | -------------------------- | --------------- |
| `00`        | `ψ`                         | `I`             |
| `01`        | `Xψ`                        | `X`             |
| `10`        | `Zψ`                        | `Z`             |
| `11`        | `XZψ` up to phase convention | `XZ`          |

Because Pauli operators are self-inverse, applying the corresponding correction reconstructs the source state up to an irrelevant global phase.

This branch structure is the core operational reason two classical bits are required.

---

## Measurement randomness versus protocol determinism

The result of a quantum measurement is probabilistic.

That does not mean the teleportation protocol is unreliable.

For a valid ideal input, every allowed measurement branch has a corresponding Bob correction. Therefore, although Alice's particular two-bit result cannot be predicted in advance for a general state, Bob can still deterministically recover the original state once the result is communicated.

This distinction is important when testing quantum algorithms:

- The measurement outcome may be random.
- The conditional correction rule is deterministic.
- The final ideal-state fidelity should remain one.

The C++ branch audit and the seeded JavaScript/Python simulations make this distinction testable.

---

## Noise and fidelity

Real quantum channels are not perfectly isolated.

The examples implement a simplified stochastic Pauli channel in which an error may apply one of:

- `X`
- `Y`
- `Z`

The noise model is deliberately smaller than a complete physical quantum-channel simulator. Its purpose is to expose the relationship between channel errors and state-transfer fidelity.

As error probability increases, the average fidelity decreases.

This demonstrates an important separation:

**protocol correctness** and **physical transmission reliability** are different properties.

A perfectly implemented correction table cannot undo every arbitrary physical error unless the system also contains suitable error-detection or error-correction mechanisms.

---

## Why density matrices matter

A pure-state vector is sufficient for a closed, isolated pure system.

It is not sufficient for every subsystem of an entangled state.

For example, the Bell state

`|Φ⁺⟩ = (|00⟩ + |11⟩) / √2`

is a pure two-qubit state.

Tracing out one qubit gives

`ρ = I / 2`

for the remaining qubit.

The remaining qubit is therefore described by a density matrix rather than by a unique pure-state vector.

This distinction becomes increasingly important in quantum communication because real channels introduce mixed states, decoherence, measurement, and environmental interactions.

The Python implementation demonstrates this explicitly rather than treating every subsystem as an independent state vector.

---

## Security and information-transfer constraints

Quantum teleportation has security-relevant physical properties, but it should not be confused with encryption.

The protocol does not automatically provide confidentiality against every possible adversarial model. Its primary function is quantum-state transfer.

The important physical constraints represented in these implementations are:

- The unknown state is not converted into a complete classical description.
- Alice's measurement generates only two classical bits.
- Bob needs those bits to select the correction.
- The original state is not retained as an independent copy.
- Entanglement alone does not create a usable faster-than-light messaging channel.
- Imperfect quantum channels can reduce fidelity.
- A production quantum network would need to account for noise, loss, synchronization, device errors, and authenticated classical communication.

The classical communication path also matters operationally. If an attacker can alter the measurement bits, Bob can apply the wrong correction and reconstruct a different state. A practical architecture therefore needs a trustworthy classical control channel even though the quantum state itself is not transmitted as classical amplitude data.

## Common implementation failures

### Incorrect qubit ordering

A frequent simulator defect is applying a gate to the wrong qubit because the implementation's bit ordering is unclear.

These implementations explicitly define:

`q0 = most significant bit`

`q1 = middle bit`

`q2 = least significant bit`

Changing this convention without changing the gate logic can silently produce incorrect teleportation results.

### Incorrect correction-bit mapping

The two classical measurement bits have different roles.

Swapping the bits changes which Pauli correction Bob applies.

A protocol can still appear to work for selected basis states while failing for phase-sensitive superpositions, so branch testing and complex-valued test states are important.

### Treating measurement as ordinary random sampling

Measurement is not simply a random choice from `{0,1}`.

The probability comes from squared amplitude magnitudes, and the quantum state must then be projected onto the selected measurement subspace and renormalized.

Ignoring state collapse produces an internally inconsistent simulator.

### Comparing raw complex arrays

Two pure states can differ by a global phase while representing the same physical state.

Direct element-by-element equality can therefore reject physically equivalent results.

The implementations use fidelity instead.

### Assuming entanglement alone transfers the state

The Bell pair does not cause Bob's qubit to become the unknown state immediately.

Bob receives a branch-dependent state and must receive Alice's classical measurement result before applying the appropriate correction.

## Edge cases represented by the implementations

The programs reject or explicitly handle:

- zero-norm input states
- empty state vectors
- invalid computational-basis strings
- dimensions that are not powers of two
- gate targets outside the available register
- identical control and target qubits
- impossible measurement branches
- invalid noise probabilities
- non-positive trial counts
- teleportation requests using more or fewer than one source qubit

These checks are important because quantum-state simulations can otherwise fail silently through incorrect indexing or normalization.

## Performance considerations

For a state-vector simulator with `n` qubits, the state contains `2^n` complex amplitudes.

This gives exponential storage growth.

For example:

| Qubits | Amplitudes |
| ------ | ---------- |
| 3      | 8 |
| 10     | 1,024 |
| 20     | 1,048,576 |
| 30     | 1,073,741,824 |
| 40     | 1,099,511,627,776 |

The teleportation protocol itself is small because it requires only three logical qubits.

The implementation strategy also matters. Rather than constructing the complete system matrix for every local operation, the programs transform basis indices directly for single-qubit and controlled gates. This reduces unnecessary matrix construction and makes the operation easier to understand.

For larger quantum circuits, performance becomes dominated by state-vector size and memory bandwidth rather than by the small number of gates used by teleportation.

## Testing strategy

A meaningful teleportation test suite should not rely on a single `|0⟩` input.

The implementations exercise:

- `|0⟩`
- `|1⟩`
- `|+⟩`
- `|−⟩`
- states with relative phase
- non-trivial complex amplitudes
- all four classical measurement branches
- normalization invariants
- invalid inputs
- stochastic channel noise

The most important ideal-protocol assertion is that the final Bob state has fidelity effectively equal to one with the original source state.

The branch tests are particularly important because random sampling may not exercise every possible measurement outcome during a small test run.

## Practical interpretation

Quantum teleportation is best understood as a coordinated protocol involving three resources:

**Entanglement**

Alice and Bob must already share an appropriate entangled state.

**Quantum operations and measurement**

Alice performs a Bell-basis measurement that consumes the original state as an independently accessible quantum state and produces a classical branch.

**Classical communication**

Alice sends the measurement result to Bob, who uses it to select the correction.

The final state appears on Bob's qubit without physically transporting the original qubit itself.

The implementations deliberately keep these resources distinct because combining them into a single vague concept obscures the mechanism of quantum information transfer.

| Implementation | Primary emphasis |

| Python | Quantum mathematics, density matrices, partial trace, fidelity, stochastic experiments |
| JavaScript | Event-driven protocol lifecycle, classical-message events, deterministic simulation, validation |

The implementations are therefore complementary rather than line-by-line translations.

The mathematical core remains consistent across all three:

`Bell-pair preparation → Bell-basis measurement → two classical bits → Bob's correction → fidelity verification`

The differences are in how the protocol is represented, tested, inspected, and connected to practical software-engineering concerns.
