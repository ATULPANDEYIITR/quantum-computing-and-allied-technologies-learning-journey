## Mathematical Expressions

I learned how to translate common algebraic expressions into Python.

### Addition and Subtraction

```text
x + y
x - y
```

### Multiplication

```text
2x + 3y
```

In Python:

```python
2 * x + 3 * y
```

### Squares

```text
x² + y²
```

In Python:

```python
x ** 2 + y ** 2
```

### Algebraic Identity

```text
(x + y)²
```

In Python:

```python
(x + y) ** 2
```

## Linear Equations

I learned how to represent and solve a linear equation in the general form:

```text
ax + b = 0
```

Rearranging the equation gives:

```text
x = -b / a
```

For example:

```text
5x + 10 = 0
```

The solution is:

```text
x = -2
```

I also implemented the solution in Python:

```python
x_solution = -b / a
```

---

## Solution Verification

I learned how to verify whether a calculated solution actually satisfies the original equation.

For:

```text
5x + 10 = 0
```

the calculated value of `x` can be substituted back:

```python
verification = a * x_solution + b
```

If the result is `0`, the solution is correct.

This introduced the concept of using programming not only to **calculate an answer**, but also to **validate the answer**.
