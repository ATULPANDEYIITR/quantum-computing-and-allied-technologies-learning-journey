# Bell States | Generate and Measure Bell Pairs

## Scope

This repository studies Bell states as the fundamental two-qubit examples of quantum entanglement. The implementations model how a Bell pair is prepared from a computational-basis state, how its amplitudes are represented, how measurements are sampled, and how the observed outcomes expose correlations.

The four Bell states are

| State | Definition | Computational-basis outcomes |
|---|---|---|
| `|Phi+>` | `(|00> + |11>) / sqrt(2)` | `00`, `11` |
| `|Phi->` | `(|00> - |11>) / sqrt(2)` | `00`, `11` |
| `|Psi+>` | `(|01> + |10>) / sqrt(2)` | `01`, `10` |
| `|Psi->` | `(|01> - |10>) / sqrt(2)` | `01`, `10` |

The signs in the superpositions are relative phases. They are not visible in ordinary computational-basis probabilities, which is why a complete Bell-state characterization requires more than observing whether two measured bits agree.

## Bell Pairs and Entanglement

A Bell pair is a two-qubit entangled state. For example,

`|Phi+> = (|00> + |11>) / sqrt(2)`.

The state is not a classical instruction saying that the pair secretly contains either `00` or `11`. Before measurement, the pair is represented by a coherent superposition of both basis states.

The computational-basis probabilities are obtained from the Born rule. If an amplitude is `alpha`, its associated probability is `|alpha|^2`.

For `|Phi+>`, the amplitudes of `|00>` and `|11>` are both `1/sqrt(2)`, so

`P(00) = P(11) = 1/2`.

The probabilities of `01` and `10` are zero.

A Bell pair therefore produces perfectly correlated computational-basis results for the `Phi` family and perfectly anti-correlated results for the `Psi` family.

## Preparing a Bell State

The standard preparation circuit starts from `|00>`.

The first operation is a Hadamard gate on qubit 0:

`|00> -> (|00> + |10>) / sqrt(2)`.

The second operation is a controlled-NOT with qubit 0 as control and qubit 1 as target:

`(|00> + |10>) / sqrt(2) -> (|00> + |11>) / sqrt(2)`.

This produces `|Phi+>`.

The other Bell states can be generated by local Pauli operations:

| Transformation from `|Phi+>` | Result |
|---|---|
| No additional gate | `|Phi+>` |
| `Z` on either qubit | `|Phi->` |
| `X` on either qubit | `|Psi+>` |
| `Z` and `X` on appropriate qubits | `|Psi->` |

The implementations use this circuit rather than inserting Bell-state amplitudes as unexplained constants. This makes the entanglement-generation mechanism explicit.

## The Four Bell States

### `|Phi+>`

`|Phi+> = (|00> + |11>) / sqrt(2)`.

The two computational-basis results always match. The relative phase between `|00>` and `|11>` is positive.

### `|Phi->`

`|Phi-> = (|00> - |11>) / sqrt(2)`.

The measurement probabilities in the computational basis are exactly the same as those of `|Phi+>`. The distinction is the negative relative phase.

A computational-basis experiment therefore cannot distinguish `Phi+` from `Phi-` merely by counting `00` and `11`.

### `|Psi+>`

`|Psi+> = (|01> + |10>) / sqrt(2)`.

The measured bits always differ in the computational basis.

### `|Psi->`

`|Psi-> = (|01> - |10>) / sqrt(2)`.

Like `Psi+`, this state produces only `01` and `10` in the computational basis. Its negative relative phase distinguishes it from `Psi+`.

## Measurement and State Collapse

Measurement is not equivalent to reading an ordinary variable without changing it.

When the simulator measures a state vector, it first calculates the probability of each possible basis outcome. A random sample is then drawn according to those probabilities.

For `|Phi+>`, a measurement produces either `00` or `11`.

Once an outcome has been observed, the simulated state collapses to the corresponding basis state. If the outcome is `00`, the post-measurement state is `|00>`.

This has an important consequence for repeated experiments. A statistical experiment involving 5,000 Bell pairs must prepare 5,000 fresh pairs. Measuring one pair 5,000 times would not reproduce the original Bell-state distribution because the first measurement has already collapsed the pair.

## Partial Measurement

The Python and JavaScript implementations also support measuring one qubit rather than immediately measuring both.

For a `Phi+` pair,

`(|00> + |11>) / sqrt(2)`,

measuring qubit 0 gives either `0` or `1`.

If qubit 0 is observed as `0`, the remaining conditional state is `|00>`. If it is observed as `1`, the remaining conditional state is `|11>`.

The important point is that the unmeasured qubit becomes conditionally determined by the measurement result because the two qubits are entangled.

This does not mean that the first measurement sends a classical message to the second qubit. The correlation is a property of the joint quantum state established during preparation.

## Computational-Basis Correlations

The programs calculate the expectation value of `Z ⊗ Z`.

For the computational basis,

- `|00>` has eigenvalue `+1`.
- `|11>` has eigenvalue `+1`.
- `|01>` has eigenvalue `-1`.
- `|10>` has eigenvalue `-1`.

Therefore the Bell states satisfy

| State | `Z ⊗ Z` expectation |
|---|---:|
| `Phi+` | `+1` |
| `Phi-` | `+1` |
| `Psi+` | `-1` |
| `Psi-` | `-1` |

This observable separates the `Phi` family from the `Psi` family, but it still does not distinguish the positive and negative relative phases within each family.

## Why Probability Counts Are Not the Whole State

The state vector contains complex amplitudes, while computational-basis measurements expose squared magnitudes.

Consider

`(|00> + |11>) / sqrt(2)`

and

`(|00> - |11>) / sqrt(2)`.

The sign does not affect the individual computational-basis probabilities:

`|+1/sqrt(2)|^2 = |-1/sqrt(2)|^2 = 1/2`.

The sign does affect interference after an appropriate basis-changing operation. Consequently, phase-sensitive measurements are required to distinguish the complete Bell basis experimentally.

This distinction is central to quantum information: a probability distribution over one measurement basis is not generally sufficient to reconstruct a quantum state.

## Python Implementation

The Python program implements a small state-vector simulator without external packages.

Its `ComplexState` representation maps two-bit computational-basis labels such as `(0, 1)` to complex amplitudes. This makes the relationship between the mathematical state vector and the implementation visible.

The gate implementations include:

- `apply_hadamard()` for creating single-qubit superposition.
- `apply_pauli_x()` for exchanging computational-basis states.
- `apply_pauli_z()` for changing relative phase.
- `apply_cnot()` for conditional target-qubit flipping.
- `create_bell_state()` for constructing all four Bell states from a common preparation circuit.

The measurement implementation uses the squared magnitude of each amplitude and then explicitly constructs the collapsed basis state.

The script also performs repeated experiments, partial measurements, `Z ⊗ Z` correlation calculations, exact simulator-side Bell-state fingerprinting, and reduced-density-matrix calculations.

The exact fingerprinting function is intentionally separated from physical measurement. A simulator has access to its internal state vector, while an experimental device does not simply expose that vector. This distinction prevents a software simulation convenience from being confused with a physical measurement procedure.

## JavaScript Implementation

The JavaScript program uses explicit complex-number objects instead of relying on a numerical package.

Its Bell-state preparation uses the same quantum operations but takes a different implementation perspective. The central state representation is a fixed object containing amplitudes for `00`, `01`, `10`, and `11`.

The JavaScript-specific part is the asynchronous measurement pipeline.

`bellPairStream()` is an asynchronous generator that yields freshly prepared Bell pairs. `collectMeasurements()` consumes the stream with `for await...of`, allowing the simulation to model a stream-oriented experiment controller.

The use of `setImmediate()` creates event-loop scheduling between generated pairs. It does not make the quantum simulation physically asynchronous or quantum; it demonstrates how an application could process sequential preparation and measurement events without blocking the Node.js event loop.

The JavaScript implementation also calculates reduced density matrices, computational-basis correlations, phase differences, partial measurements, and validation failures.

## C++ Case Study

The C++ program models a research team's two-qubit Bell-pair validation pipeline.

The system uses a fixed `std::array` state vector with four amplitudes. The basis index mapping is

| Index | Basis |
|---:|---|
| `0` | `|00>` |
| `1` | `|01>` |
| `2` | `|10>` |
| `3` | `|11>` |

The `BellState` enumeration provides explicit identities for the four Bell states rather than representing them as arbitrary strings.

The preparation pipeline starts with `basisState(0)`, applies Hadamard to qubit 0, and then applies CNOT from qubit 0 to qubit 1. Pauli transformations produce the remaining Bell states.

The measurement batch intentionally prepares a fresh state for every trial. This models an experimental run in which each observation corresponds to a newly generated pair.

The case study validates three separate properties:

- State normalization verifies that total probability remains one.
- Computational-basis support verifies that `Phi` states never produce `01` or `10`, while `Psi` states never produce `00` or `11`.
- `Z ⊗ Z` correlation verifies the expected sign of the computational-basis correlation.

The C++ implementation also constructs the density matrix using `rho = |psi><psi|` and computes the reduced density matrix of one qubit.

## Reduced Density Matrix

For a pure Bell state, tracing out either member of the pair gives

`I / 2`.

In matrix form, the reduced state is

`[[1/2, 0], [0, 1/2]]`.

This means that an observer restricted to one member of a Bell pair sees a maximally mixed single-qubit state.

The joint state nevertheless contains strong correlations.

This is an important distinction between local information and joint information. The individual qubit does not reveal which Bell-state outcome will occur, while the pair's joint measurement can exhibit deterministic correlations.

## Bell-State Identification

Computational-basis measurements divide the Bell basis into two indistinguishable pairs:

`Phi+` and `Phi-` both produce `00` or `11`.

`Psi+` and `Psi-` both produce `01` or `10`.

To distinguish the members within each pair, the measurement basis must be changed so that relative phase becomes observable through interference.

A common technique is to apply Hadamard gates before computational-basis measurement. The basis transformation converts phase information into measurable population differences.

The exact state-vector comparison used in the Python simulator is not a substitute for this physical procedure. It is included as a software diagnostic because the simulator knows its own internal amplitudes.

## Finite Sampling

The theoretical probability of each allowed computational-basis result in a Bell state is `1/2`, but a finite experiment will generally not produce exactly equal counts.

For example, a batch of 4,000 `Phi+` measurements may contain slightly different counts for `00` and `11`.

The C++ validation therefore checks the structural support of the distribution rather than demanding an exact 50/50 split.

A statistically rigorous hardware experiment would go further by specifying confidence intervals, uncertainty estimates, detector error models, state-preparation errors, and an acceptance threshold before collecting data.

## Numerical Considerations

The simulations use floating-point arithmetic.

Ideal Bell states contain amplitudes such as `1/sqrt(2)`, which are represented approximately in binary floating-point. The implementations therefore use tolerances when checking values that theoretically should be zero or when validating normalization.

Renormalization after gate operations prevents accumulated numerical scaling errors from silently changing the total probability.

For two qubits this is inexpensive. A general state-vector simulator for `n` qubits requires `2^n` complex amplitudes. The exponential growth of the state representation is a fundamental scaling constraint for classical simulation.

## Common Implementation Errors

### Measuring a state without respecting probability amplitudes

Choosing each basis state with equal probability regardless of its amplitude is incorrect. The Born rule requires the probability of a basis state to be the squared magnitude of its amplitude.

### Treating a Bell pair as two independent random bits

Independent random bits can reproduce some marginal statistics, but they do not reproduce the joint quantum state or its phase-sensitive interference behavior.

### Reusing a collapsed pair

After measurement, the simulated state is no longer the original Bell state. Repeated independent observations require repeated preparation.

### Confusing correlation with complete state identification

Knowing that two computational-basis bits always agree identifies the `Phi` family but does not distinguish `Phi+` from `Phi-`.

### Ignoring relative phase

The minus sign in `Phi-` or `Psi-` does not alter computational-basis probabilities, but it changes interference under basis transformations.

### Treating simulation output as direct hardware observation

A simulator can inspect its internal amplitude vector. A quantum processor normally exposes measurement results rather than a direct dump of the full wavefunction.

## Validation Rules Demonstrated by the Programs

The implementations reject invalid operations such as:

- selecting a nonexistent qubit;
- using the same qubit as both CNOT control and target;
- constructing a zero state and attempting to normalize it;
- using an invalid Bell-state identifier;
- accepting a state whose total probability differs materially from one.

These checks are not merely input hygiene. An invalid state vector can make every later measurement result meaningless, so normalization and gate validation belong close to the state-manipulation layer.

## Security and Experimental Integrity

Bell-pair experiments can be used in quantum communication and cryptographic protocols, but the simulation here does not implement a cryptographic protocol or establish security by itself.

For experimental systems, measurement records should preserve the association between preparation settings, pair identifiers, timestamps, detector outcomes, and calibration information. Uncontrolled modification of those records could invalidate statistical conclusions.

A software simulator should also avoid presenting generated pseudo-random results as evidence of physical randomness. The random generator in these programs is an implementation mechanism for sampling the theoretical distribution.

## Performance Characteristics

For this two-qubit simulator, the state vector contains only four complex amplitudes, so individual gate operations are effectively constant-size.

The general state-vector model does not remain constant-size as the number of qubits grows. With `n` qubits, there are `2^n` computational-basis amplitudes.

Consequently:

- memory grows exponentially with qubit count;
- state-vector gate operations generally touch an exponentially growing number of amplitudes;
- repeated measurement experiments add a factor proportional to the number of trials;
- density matrices require substantially more storage than state vectors.

The implementations deliberately remain at two qubits so that the mathematical mechanisms remain directly inspectable.

## Relationship Between the Three Implementations

The Python implementation emphasizes mathematical transparency and reusable simulation functions.

The JavaScript implementation emphasizes an event-driven experiment pipeline, asynchronous pair generation, and application-level processing of measurement events.

The C++ implementation treats Bell-pair generation as a controlled technical case study with explicit validation, batch measurement, statistical support checks, and reduced-state analysis.

All three represent the same underlying quantum mechanics, but their software structures serve different purposes rather than being line-by-line translations of one another.
